Entry for the [make.fun bounty "Funniest Forecast for a City That Isn't"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf).

`main.py` (Python standard library only, deterministic) writes one line — a
weather forecast for the nonexistent city of Flibberton — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> Sunny in Flibberton today, high of 74, with a 90% chance of frogs and a 10% chance the frogs are judging you.

Run it with:

```sh
python3 main.py
```
